# Что нового в Архиве

## 1.5.0
- Android: выпускная сборка с постоянной подписью — новые версии ставятся поверх, без удаления и без потери данных
  (после того как в репозитории задан ключ подписи, см. README).
- У каждой сборки есть номер версии; в описании загрузки — список изменений.
- Подготовлена отправка в TestFlight для iPhone (нужен платный аккаунт Apple, см. README).

## 1.4.0
- Резервная копия и экспорт папок создаются по частям — не переполняют память на большом архиве, видно «N из M».
- Большие папки, избранное и поиск рисуются частями по мере прокрутки; поиск не тормозит при наборе.
- Поиск дубликатов и «Выбрать все» быстрее на большом архиве.

## 1.3.0
- Обрезка видео по времени без перекодирования: мгновенно, без потери качества, работает на iPhone.
- Редактор фото расходует меньше памяти на больших снимках.
- Голосовое сохраняется, если во время записи свернуть приложение или архив заблокируется.
- «В галерею»: фото и видео — прямо в «Фото» (iPhone) и в альбом «Архив» (Android).

## 1.2.0
- В приложении файлы хранятся в личной папке приложения, а не во внутренней базе; старые файлы переносятся сами.
- Автотесты хранения, шифрования, переноса и корзины.

## 1.1.0
- Приложение для iPhone и Android, безопасность, защита данных, работа с материалами, жесты, оформление.

# Архив

Мобильный приватный архив, проектируемый только для iPhone и Android.

## Основа интерфейса
- Главный экран: только люди с пользовательскими аватарками. Вкладки «Все» нет.
- Карточка человека: Фото · Видео · Скриншоты · Аудио · Текст.
- Для материалов предусматривается источник: Telegram, MAX, WhatsApp, Instagram, VK, Одноклассники или произвольный источник.

## Приватность
Репозиторий содержит только код. Личные фото, видео, скриншоты, аудио и тексты не должны коммититься в GitHub. До подключения реального хранилища используются только фиктивные данные. План: обязательная разблокировка, приватное хранилище, минимизация метаданных и отсутствие чувствительных превью до разблокировки.

## Запуск
npm install
npm run dev

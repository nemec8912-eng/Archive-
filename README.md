# Архив

Личное закрытое мобильное хранилище для iPhone и Android: фото, видео, скриншоты, сохранённые переписки, голосовые записи и текстовые заметки.

Это не социальная сеть и не файловый менеджер для работы: нет профилей, ленты, лайков, комментариев и публичного доступа.

## Что умеет

- **Главный экран** — категории Фото, Видео, Скриншоты, Переписки, Голосовые, Заметки со счётчиками и поиск.
- **Папки** — свои папки, сетка миниатюр, выбор одного или нескольких материалов.
- **Просмотр** — фото и скриншоты на весь экран с перелистыванием, встроенный видеоплеер, проигрыватель голосовых с дорожкой и перемоткой, читаемые переписки с вложениями.
- **Заметки** — текст, прикреплённые фото и голосовые, выбор папки.
- **Добавление** — кнопка «+»: из галереи, с камеры, запись голосового, заметка, скриншот, новая папка.
- **Избранное** — ссылка на материал, не копия.
- **Действия** — открыть, переименовать, переместить, копировать, в избранное, поделиться, удалить.
- **Корзина** — удаление только перемещает в корзину; восстановление в исходную папку; «Удалить навсегда» и «Очистить корзину» — только после подтверждения.
- **Настройки** — блокировка кодом, смена кода, скрытые папки, занятое место, резервная копия в файл.

## Приватность

- Материалы хранятся только на устройстве (IndexedDB) и никуда не отправляются.
- При включённой блокировке содержимое не отображается до ввода кода; код запрашивается и при возвращении в приложение. Хранится только хеш кода.
- Репозиторий содержит только код. Личные файлы не коммитятся (`.gitignore`: `private-media/`, `uploads/`).
- Резервная копия — один файл `.archive`, создаётся на устройстве; храните его в надёжном месте.

## Установка на телефон

Приложение — устанавливаемое веб-приложение (PWA), работает офлайн.

- **iPhone:** открыть адрес приложения в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открыть в Chrome → меню → «Установить приложение».

Нужен адрес с HTTPS (требование iOS/Android для камеры, микрофона и шифрования кода).

## Разработка

```bash
npm install
npm run dev      # локально, доступно с телефона в той же сети
npm run build    # готовая сборка в dist/
```

Стек: React 18, Vite 5, без сторонних UI-библиотек. Структура:

```
src/
  App.jsx            маршрутизация экранов
  store.jsx          данные архива, корзина, избранное, папки
  security.jsx       блокировка
  ui.jsx             навигация, всплывающие окна, уведомления
  actions.js         действия с материалами
  lib/               хранилище, импорт медиа, резервные копии
  components/        общие элементы, иконки, меню
  screens/           экраны
```

Эталон проекта — техническое задание и утверждённый тёмный макет. Новые разделы, функции и изменения внешнего вида — только после согласования.
